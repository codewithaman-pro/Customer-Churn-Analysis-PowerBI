# 📊 Customer Churn Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing customer attrition (churn) for a telecommunications company using Power BI. The objective is to identify key drivers of churn and recommend strategies to improve customer retention.

## 💡 Key Insights
- **Total Customers:** 7,043
- **Overall Churn Rate:** 26.54%
- **Contract Impact:** Customers on **Month-to-month contracts** show the highest churn rate (**42.71%**), compared to Two-year contracts (**2.83%**).
- **Payment & Internet Service:** Higher churn is observed among users with **Fiber Optic** internet service and those using **Electronic Check** as their payment method.

## 🛠️ Tools & Technologies
- **Power BI Desktop** (Data Transformation, DAX Measures, Visualizations)
- **Power Query** (Data Cleaning & Formatting)
